## URL contract

- `?frame=N` paints one deterministic frame and stops; `?stats=1` counts canvas `stroke()` and `fill()` calls into `window.__paintStats`.
- `?at=<preset>`: `altar-dawn`, `corridor-moon`, `court`, `dance`, `town`, `bay`, `mouth`, `gorge-tombs`, `narrows`, `lenika`, `villa`, `terraces`, `peak`.
- `?tod=0..1` sets the hour; `?px= ?pz= ?yaw= ?pitch=` set the pose; `?q=0..2` pins the quality tier; `?dpr=` the pixel ratio.
- `?ledger=1` opens the ledger lens; `?prayer=<key>` opens a text, `&pt=<seconds>` sets how far the writing has got.
